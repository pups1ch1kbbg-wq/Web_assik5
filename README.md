# JavaScript Basics — Assignment 5

## About the Project

This project demonstrates the basics of JavaScript, HTML, and CSS through interactive web pages. It includes simple exercises covering variables, events, DOM manipulation, a calculator, and a To-Do list.

## Features

- **Task 0:** Introduction to JavaScript using `console.log()` and `alert()`.
- **Task 1:** Variables, data types, arithmetic operations, and string concatenation.
- **Task 2:** Change paragraph text using a button.
- **Task 3:** Change background color and font size.
- **Task 4:** Add and remove items from a list.
- **Task 5:** Change an element's color using mouse events.
- **Task 6:** Display input values while typing.
- **Task 7:** Calculator for addition, subtraction, multiplication, and division.
- **Task 8:** Interactive To-Do list with adding, deleting, and completing tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the navigation menu to explore the different tasks.

## Learning Objectives

- Understand JavaScript variables and data types.
- Practice DOM manipulation.
- Work with browser events.
- Create interactive web elements.
- Implement basic calculator functionality.
- Build a simple To-Do application.
